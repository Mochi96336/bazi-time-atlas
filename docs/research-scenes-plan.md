## 1. 為什麼重做

`testindex.html` 證明了兩件事：

1. **銜接動畫幫助理解。** 最有效的幾段都不是單張圖，而是兩張圖之間的「變形」：
   - 庚寅拆成天干、地支 → 兩個齒數不同的環同步轉，60 步才同時回到起點；
   - 六十甲子圓環 → 展開成扇形，三圈疊在固定紅針下；
   - 1,980 年 → 鏡頭推近零點，看見公曆圈「還差 20 年」；
   - 扇形 → 攤平成兩條直尺（60 與 400），共同刻度出現 1,200；
   - 146,097 日 → 20 個 400 年方塊，才被 60 整除；
   - 公曆環 → 黃經環 → 從冬至剪開、攤成直線 → 再收回圓環（座標轉換）。

   讀者看到的是「同一個東西怎麼變成下一個東西」，不必自己把兩張圖對起來。

2. **一幕一句白話結論**（「兩個週期回來了。」「還差 20 年。」「146,097 日。」）比現在研究頁的長段落好讀。

但它不能直接用：米白紙底＋紅色的編輯風和首頁不同；數據是複製進來的陣列；6 段腳本層層覆寫；後半段 TT、UT1、N-body 等名詞回到正文；浮動控制台壓住內容。詳見 2026-11-26 的評估。

現在的 `recurrence.html` 已經是深色＋黃銅，01 的扇形也沿用首頁語彙，問題是：**每節是一長頁文字＋並排的圖，圖與圖之間沒有連結**。

## 2. 從 lemo-opuscar 拿到的知識

lemo-opuscar 是「用程式碼做影片」的風格庫。它的影片做法不適用（固定長度、配樂、旁白），但導演方法和幾個風格的規則可以直接轉成網頁規則。來源：`DIRECTOR.md`、`TECHNIQUE.md`、`styles/precise-mechanism`、`styles/dataviz`、`styles/oscilloscope-math`、`styles/dark-documentary`。

### 2.1 拿來用

| lemo 的規則 | 在研究頁的意思 |
| --- | --- |
| **畫面是時間的函數**：`render(t)` 必須是純函數，不依賴上一格（TECHNIQUE §2） | 每幕寫成 `render(scene, p)`，`p` 是 0–1 的進度。任何狀態都能直接跳到、倒退、截圖測試；「減少動態」設定直接跳到 `p=1`。 |
| **一條時間軸驅動全部**（TECHNIQUE §3） | 一個 `scenes.js` 定義幕的順序、標題、結論句、資料來源、銜接方式。頁面、目錄、測試都讀它。 |
| **機器是真的**：齒輪照真實齒比轉，畫面上的數字由模型算出（precise-mechanism §1） | 環的轉動一律由 Δ 年／日換算出相位；讀數、殘差都從 `src/recurrence/`、`src/research/` 即時算，不寫死。 |
| **顏色就是結構**：每個子系統一個固定角色，其他退成中性；**只有一個強調色**；「聚焦模式」只讓因果兩端保留顏色（precise-mechanism §3） | 年序、日序、公曆、節氣四個系統的材質角色固定，不隨章節改變。當幕討論的那一圈才亮，其餘退回漆面。 |
| **轉場在物件內部完成**：切開、展開、對位剪接；不用溶接、滑頁（precise-mechanism §6、dataviz §5、oscilloscope §6） | 幕與幕之間只用儀器本身的動作：轉、推近、展開、剪開、抬起、留影。見第 4 節。 |
| **一個主角標籤**，已解釋過的退成灰（precise-mechanism §4） | 每幕只有一個主要讀數；上一幕的讀數變成銀灰小字留著，下一幕再消失。 |
| **比較時，數字是主角**（≥120 px），產生它的兩端用引線標出，停留 ≥2.5 秒（precise-mechanism §4） | 「1,200」「8,000」「24,000」這類幕，大數字＋兩端來源（60 與 400）用引線連到環上。 |
| **閱讀時間**：中文字數 ÷ 4.5 ＋ 1.5 秒（DIRECTOR §7，`readcheck.mjs`） | 換成捲動長度：每幕的捲動距離至少要給足這段閱讀時間；寫成檢查，取代人工估。 |
| **一個招牌鏡頭**，放在情緒高點（DIRECTOR §3、§8） | 招牌鏡頭：三圈在固定針下從 +1,980 轉到 +24,000，公曆圈的 −20 年缺口收攏到 0。全頁只有這裡用最長的動畫。 |
| **節奏要有快慢，至少一次停頓**（DIRECTOR §7） | 01 的四步推導可以快；24,000 閉合後停一拍；02「十二節沒有一個回到零」前也停一拍。 |
| **掃描才看得見**、**留下回聲**（dark-documentary §1） | 2026 的狀態在推進時留下銀灰「回聲」，和現在的暖色對照。這正好就是你的「暖＝現在、冷＝記憶」。 |
| **常見失敗**：主體太小、同色疊同色、轉場中出現空白畫面（DIRECTOR §10） | 列進驗收：轉場的每個中間格都要有主體，不能只剩背景。 |
| **審查方法**：每秒一張的總覽圖、關鍵動作 0.2 秒一格的連續格（TECHNIQUE §8） | 每幕在 `p=0、0.5、1` 截總覽圖；每個轉場截 10 格連續圖，比對主線基準。 |

### 2.2 不拿

- 任何風格的外觀：precise-mechanism、swiss-motion、dataviz 都是淺色紙底，和首頁衝突。`testindex.html` 的米白＋紅就是從這類風格來的。
- 自動播放、固定長度、配樂與音效。研究頁由讀者控制節奏。
- 手繪鉛筆、磷光輝光、雕版筆觸等裝飾性材質。

## 3. 視覺語言：「近看的黃銅儀器」

直接沿用首頁，不另造一套：

| 元素 | 首頁現況 | 研究頁用法 |
| --- | --- | --- |
| 底 | 深色漆面 | 同。不換底色、不換頁面背景。 |
| 固定指針 | 頂端一根金色細針 | 每幕的「比較點」。永遠固定，環在它下面轉。 |
| 同心環 | 年／月／節（黃銅帶）／日／時 | 研究頁只取需要的圈：01 用年序、公曆、日序三圈；02 用黃銅帶（太陽黃經、十二節）。 |
| 黃銅帶 | 太陽的一年 | 只用在真正的太陽：黃經、節氣。公曆圈是漆面。這樣 01 → 02 的「公曆不是黃經」可以用材質講：公曆圈不是黃銅，黃經圈才是。 |
| 格內干支 | 宋體干支寫在格子裡 | 同。讀數用同一字型。 |

顏色角色（依你的美感筆記：亮度很稀缺；暖色代表現在，冷色代表記憶）：

- **暖（黃銅／金針）**：當下討論的狀態、被比較的時刻。
- **冷（月銀）**：基準 2026 的回聲、已經講過的東西。
- **中性漆面**：其他所有結構。
- **紅**：只用於真正的缺口與錯誤（「還差 20 年」、「沒有回到零」）。一屏最多一處。

> 和 `research-visual-constitution.md` §5.2 的衝突：憲法寫「current = 青、candidate = 琥珀」。我的建議是改成上面的「暖＝現在、冷＝回聲」，與首頁一致。需要你確認（見第 8 節）。

字：沿用首頁的 Noto Sans TC，加干支用的宋體。數字用等寬數字（tabular nums），不加第三種字型。

## 4. 銜接動畫的語法

只允許六種動作，全部是「同一個儀器在做事」：

| 動作 | 意思 | 用在 |
| --- | --- | --- |
| **轉**（rotate） | 時間經過 | Δ 年增加時，三圈在固定針下轉；有慣性、連續減速，和首頁拖動的物理一致 |
| **推近／拉遠**（push / pull） | 看細節／看全貌 | 推近零點看 −20 年缺口；拉遠回到整圈 |
| **展開**（unroll） | 換座標：角度 → 直線 | 公曆環與年序環攤成直尺比較 60 與 400；黃經環從冬至剪開成直線軸 |
| **抬起**（lift） | 把一圈拿出來單獨看 | 把公曆圈抬起，對照「它只是季節代理」；把日序圈抬起，數 146,097 |
| **留影**（echo） | 保留前一狀態 | 2026 的位置留成銀灰回聲，26026 的位置是暖色 |
| **扣除**（subtract） | 拆解同一批資料 | 02 延伸：完整偏移扣掉平均，剩下年內起伏 |

規則：

- 沒有淡入淡出、滑頁、彈跳、閃色。（首頁 v6 的閃色已被否決過。）
- 每個動作都能被捲動來回拖動：`p` 從 0 到 1 是動作的完整過程，倒捲就倒放。
- 轉動的角度必須是真的：由 Δ 換算，不是為了好看調出來的。
- 動作的速度曲線是連續的，不會突然起停。
- 「減少動態」：直接顯示每幕的最終狀態，不播放過程。

### 三類畫面的處理原則（2026-11-26 補）

**沒有圓盤的幕：不離開儀器。** 原本想攤成直尺、棒棒糖圖、累積圖的幕，全部改成儀器上的狀態：
- 「幾步之後回來」用**回聲軌跡**表示：每走一步，起點在圈上留一道銀色刻線，最後一道回到針下（1.3、1.4、2.3）。
- 「差多少」刻在**同一條帶上**（1.2 的紅弧、2.2 的金線）。
- 只有 2.4（軌道）讓鏡頭從正面轉成俯視，黃銅帶變成軌道。這是鏡頭動作，材質不換。
- 延伸題與「模型邊界與來源」才離開儀器，改成普通文章版面，配小圖。

**相對動畫：兩個儀器狀態之間的插值。** 每幕的狀態＝｛Δ、各圈相位、鏡頭（縮放、中心）、光（每圈壓暗多少）、標記｝。捲動的 p 對這些量插值：
- 圈的角度一律由 Δ 換算。跨很大的 Δ 時（1,980 → 24,000）不讓圈狂轉（會閃爍）：以 1,200 年為一步跳格、每步之間平滑轉過，畫面註明「每格 1,200 年」。
- 回聲刻線依 p 逐道出現。光的變化是壓暗程度連續變化，不閃。

**很多字：一幕最多一句結論加一行說明。**
- 同一個畫面需要多段解釋時，拆成同一幕的幾個文字步：畫面不動，底部的句子換下一句。
- 推導（146,097 ÷ 60 餘 57 等）收在句中可點開的一行。
- 來源、模型邊界、名詞表放到主線之後的附錄，用一般文章排版；每幕的圖說列（左上角）連到對應的來源段落。

### 第二階段：序幕＋01 捲動原型（2026-11-26）

原型：`prototypes/research-scenes/scroll.html`（真實首頁輪盤；`?at=<幕>:<p>` 可直接跳到某處）。

| 幕 | 捲動中發生的事 |
| --- | --- |
| 0.1 起點 | 與首頁同一畫面 |
| 0.1 光 | 針下一欄以外逐漸壓暗，柱名從右側淡入 |
| 0.2 十乘十二 | 其他圈壓暗；日序圈每格的兩字拆成兩排：外排天干（10 格重複）、內排地支（12 格重複），與「庚」「寅」同字的格亮起，只有針下那格兩排都亮 |
| 0.3 合回 | 兩排合回日序；中間月圈換成公曆 400 年圈 |
| 1.1 | Δ 每次跳 60 年，共 33 步：年序每步都回到丙午，日序每步跳一段，第 33 步（1,980 年）才一起回來 |
| 1.2 | 鏡頭推近；紅弧從針下長到公曆起點：「還差 20 年」 |
| 1.3 | 倒回 0；每 60 年一步，公曆起點每步移 54°，留下銀色軌跡；第 20 步（1,200 年）回到針下 |
| 1.4 | 每 400 年一步，日序起點每步偏 3 格，軌跡 20 道；8,000 年回到針下 |
| 1.5 | 每 1,200 年一步，年序與公曆不動，只等日序；第 20 步＝24,000 年，三圈「回到起點」 |

做法：
- 每格畫面＝捲動進度的純函數。圈的角度由 `recurrenceState(Δ)` 算出；Δ 只以整個週期跳步，兩步之間圈沿最短方向轉，所以不會轉到閃爍。
- 文字換幕時淡出淡入 0.18 秒。
- 手機版進入 01 時，首頁鏡頭改用 680px 寬（compact），再橫向平移；1.2 把針移到左側。
- 原型限制：手動轉動 SVG 時，首頁 WebGL 的細紋理不跟著轉。正式版要用渲染器自己的 pose API。

### 第三階段：02 捲動原型（2026-11-27）
