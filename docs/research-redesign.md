## 2. 原則：每節「一句話、一張圖、一個深入」

每一節固定成三層，其他全部收起：

1. **一句話**（常態顯示）：白話結論，就是讀者帶走的那句話。
2. **一張主圖**（常態顯示）：證明那句話的圖，預設狀態就要有資訊。圖下一行「怎麼讀」。
3. **一個深入**（摺疊）：推導、工具、來源、模型邊界。

再加一條**橋接句**接到下一節。

### 負空間

- 第一屏只放：標題、一句答案、三步驟路線圖（見 3.1）。拿掉對齊表、八格日期卡、里程碑按鈕。
- 節與節之間至少 120px 空白，只放一條橋接句，不放卡片。
- 主圖左右不放並排文字欄（目前的「讀法」右欄、圖旁說明）。說明一律放在圖下方一行。
- 結論句寬度限制在 32–36 個全形字一行，左側不加框線以外的裝飾。
- 同一屏不超過一個強調色區塊（現在 01 有藍框＋金框＋灰框三塊）。

### 展開／收合清單

| 常態顯示 | 收進摺疊（深入） | 移除或合併 |
| --- | --- | --- |
| 每節白話結論 | 01：+400／+1,200／+8,000 補充驗算（B 已做）| 開頭的四柱對齊表 |
| 01 主圖（三軌或相位扇，預設 Δ=1,980）| 01：年度時間條、日期輸入、Δ 滑桿、播放 | 開頭八格「基準」日期卡（移進 01 工具摺疊）|

## 3. 要補／要換的圖

### 3.1 開頭：答案路線圖（新增）

一條橫向時間軸，取代開頭的對齊表與目錄：

```
0 年 ──── 1,980 年 ──────────── 24,000 年 ──────→
          年柱＋日柱             曆法上三個循環      真正的「節」
          一起回來               全部對上            差 10–14 天
          (01)                   (01)                (02)
                                                    → 年／月可以一樣，日／時無法確定 (03)
```

三個節點就是三章的入口。讀者第一屏就知道答案與路線。

### 3.2 01：三軌對齊圖（取代數字卡片階梯）

三條水平軌：年序（60）、日序（60）、公曆 400 年結構。每條軌上一個指針，0 在中央。

- 預設顯示 **Δ=+1,980**：年序 0、日序 0，公曆 −20（偏離）。讀者一眼看到「還差一條」。
- 切到 **+24,000**：三條都到 0。
- 動畫（E3 原計畫）：捲動時從 0 → 1,980 → 24,000，指針依序歸零。

和 B 的相位扇的關係：相位扇是同一份資料的半圓版本。建議**保留 B 的相位扇當主圖**（已有 160 格、Δ 驅動、測試齊全），但：
1. 預設 Δ 改成 +1,980（目前是 0，三圈全 0、無資訊）；
2. 圖上直接放兩個切換：「+1,980」「+24,000」，取代上方的大卡片階梯；
3. 圖說一行：「外圈公曆、中圈年序、內圈日序；指針在 0 代表回到起點。」

如果之後使用者測試（D7）顯示半圓難讀，再換成三軌直線版。先不要同時存在兩種。

### 3.3 02：保留棒棒糖圖＋累積圖，軌道圖收起

- 棒棒糖圖不動（全頁最清楚）。
- 累積圖放在棒棒糖圖下方，回答「是突然還是慢慢偏的」：0.5 → 1.8 → 10.9 天。
- 軌道俯視圖收進「深入：同一個太陽位置，為什麼到達時間不同？」，並在摺疊開頭補一張**兩格簡圖**：2026 與 26026 的地球軌道，近日點位置轉了，立春那一點到達的日期因此提早。現在的俯視圖資訊太密，適合當深入的第二張。

### 3.4 03：一張四柱判定圖

把 A 的大字四柱卡與證明分岔圖合成一張：

```
看太陽位置就能決定 ─┬─ 年柱  丙午  ✓
                    └─ 月柱  庚寅  ✓
還要知道地球轉到哪 ─┬─ 日柱  ？    ±7 天不確定
                    └─ 時柱  ？
```

左邊是原因（兩個分支），右邊是答案（大字）。「為什麼兩句同時成立」的區塊刪除，改成圖下一行說明。

### 3.5 名詞：就地解釋

名詞第一次出現時加虛線底線，點一下在原處展開一行解釋（不跳頁）。頁尾名詞表保留作索引。

### 3.6 SVG 圖內字級

相位扇、俯視圖內還有 8–10px 的字，手機上更小。主圖內的字至少 11px（C1 規則），做不到就把標籤移到圖外。
