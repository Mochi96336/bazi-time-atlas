# R22 P9｜把「缺的那一層」寫回半圓，而不是再加一張儀表板

## 實驗假設
P8 的「差距弧段」在 320px / +1200 年時只增加約 36×9px 的視覺區域，使用者不容易辨認；「2/3 閉合」知道閉合數量，卻未能指出**缺的是日序**。這輪只問：**半圓上的實際缺口能不能直接說出條件名稱與帶單位的偏差？**

與 P7（原版）及 P8（`gap`／`closure`）並存的明確實驗入口：
`?r22=1&r22-study=missing&date=2026-09-13&delta=1200`。

## 如何運作
- 用**原本的** `recurrenceState` 相位，經由 P8 已驗證的 180° 投影導出標記位置。不設第二個 Δ，也不創造新階段。
- 只在 **Δ>0、有一到兩層真的回到 0、其餘條件尚未閉合** 時，在尚未閉合的軌道上用細引線標示其目前相位：例如 `日序 −9日`。
- 不另建右側 summary，不新增燈號、色塊進度條或刻度。原先的不足 10px 手機顯示的微型純數值，於 P9 實驗內退場，取代為**同一個標記旁**較大的「名稱＋有號差值＋單位」。
- 完全不在零點附近補出假的 60 日累積旋轉。最短有號偏差與真實累積圈數仍是兩件事。
- 若 Δ=0（只是基準）、Δ=24000（三層已閉合）或所有三層都未閉合（沒有值得特別教學的部分重遇），不產生此教學標注。
- 若日序不可用（例如 2/29 走到不存在的同月同日），不標成數值差距。

## 預先指定的判讀樣本

| Δ | 圖上 P9 應提供的直接註記 | 理由 |
|---|---|---|
| +0 | 無 | 基準不等於重遇 |
| +400 | `年序 −20年`、`日序 −3日` | 一層已閉合，餘兩層缺口都要被看見 |
| +1200 | `日序 −9日` | 核心測試：先從圖讀出哪一層仍未閉合 |
| +1980 | `公曆 −20年` | 首次年＋日局部重遇，不等於三層回零 |
| +8000 | `年序 +20年` | 已閉合的兩層不該奪走主圖焦點 |
| +24000 | 無 | 原有三個歸零標記已表達閉合，不再疊第四種象徵 |

## 自評與可否決條件

這是一個**標註策略**，不是已完成的視覺勝利。原先 P8 的「小燈號」問題沒有靠新裝飾解決；P9 的風險轉為：
- 在 +400 年的兩個標註彼此重疊；
- 標註太靠近軌道，妨礙從半圓讀取相位；
- 320px 看似可見但文字實際不可讀；
- 桌面偏大，破壞幾何主體、使主圖變成圖表；
- 在常態下隱藏標註可能被誤認為「沒有偏差」，需透過 `r22-study=missing` 的實驗性質說明，不升格為正式預設。

**驗收流程**：先用 pure tests 檢查真實相位、單位、可用性，再用真實 Chrome 畫面逐組比較 P7 與 P9 的 320／390／1440px；P9 若未顯著改善核心 +1200 判讀或引入更嚴重的遮擋／儀表板感，仍然否決。作者自評不能冒充獨立 AI 評審；人類裁判保留選擇權。
